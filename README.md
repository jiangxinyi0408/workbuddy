# 个人移动工作台

专为财产保险业务员打造的一站式移动工作台 PWA 应用。包含 6 大模块，数据本地存储，隐私安全。

## 功能模块

### 📋 1. 保险工作台
- **任务管理**：记录每周、当天、第二天待完成工作，支持优先级和业务分类
- **每日总结**：每天晚上 21:00（可设置）自动弹出当日工作总结，含完成率、未完成项、明日待办
- **智能工作时间推算**：积累 1 个月数据后，根据历史完成率和任务耗时，智能预估明天所需工作时间

### 🏓 2. 乒乓球时间规划
- **活动登记**：提前登记乒乓球活动时间、地点、类型
- **自由时间计算**：自动计算工作日 18:00 后 + 周末全天，扣除乒乓球时段后的可用自由时间
- **不可用标注**：可手动标注其他已有安排

### 📚 3. 英语口语学习
- **90 天进阶计划**：分 3 个阶段（基础重建 → 场景强化 → 实战提升）
  - 阶段 1（1-30天）：口语跟读 + 基础听力 + 核心词汇，每天 15-20 分钟
  - 阶段 2（31-60天）：旅游全场景对话 + 影视听写，每天 20-25 分钟
  - 阶段 3（61-90天）：无字幕理解 + 自由表达，每天 25-30 分钟
- **进度追踪**：连续学习天数、累计时长、完成度
- **每日一句**：实用旅游口语
- **核心词库**：20+ 旅游高频词汇

### 📰 4. 热点新闻资讯
- **多源聚合**：新华网、央视、BBC、36氪、华尔街见闻
- **分类浏览**：热点 / 国际 / 科技 / 财经
- **离线缓存**：2 小时缓存，离线可看

### ⚖️ 5. 减肥管理
- **体重记录**：早晚体重录入，折线图趋势展示，目标线参考
- **饮食拍照识别**：上传食物图片，AI 自动识别食物种类和卡路里（需配置 Gemini API Key）
- **手动录入**：未配置 API Key 时可手动添加食物
- **每周饮食推荐**：基于本周饮食、体重变化和健康指标生成个性化推荐
  - 已预填健康指标：低密度脂蛋白过高、胆固醇过高
  - 推荐低胆固醇食谱，标注需避免和推荐食物
- **基础版推荐**：无需 API Key，基于内置低胆固醇食物库生成建议

### 💰 6. 存款还款
- **收入记录**：按月记录底薪、提成、奖金
- **贷款管理**：按银行分组，记录本金、当前余额、月供、利率、到期日
- **还款追踪**：记录每月还款，自动更新余额
- **总览看板**：本月收入、欠款总额、月供总额、净现金流、银行分布饼图

## 使用方法

### 1. 访问应用
在手机浏览器中打开 `index.html`。

### 2. 添加到桌面（像 App 一样使用）
- **iOS Safari**：点击分享按钮 → 添加到主屏幕
- **Android Chrome**：点击菜单 → 添加到主屏幕

### 3. 配置 AI 识别（可选）
- 进入「更多」→「应用设置」
- 在 Gemini API Key 处填入你的 Key
- 到 [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 免费获取
- 配置后可使用食物拍照识别和 AI 饮食推荐

### 4. 设置个人信息
- 在「应用设置」中填写身高、目标体重
- 每日总结时间可调整（默认 21:00）
- 健康指标已预填（低密度脂蛋白过高、胆固醇过高）

## 数据与隐私
- **所有数据存储在手机本地**（IndexedDB），不上传任何服务器
- AI 识别功能会将图片发送到 Gemini API 处理
- 支持「导出全部数据」备份到文件
- 支持清空所有数据

## 技术栈
- PWA（渐进式网页应用）
- 原生 HTML5 + CSS3 + Vanilla JS（无框架）
- IndexedDB 本地存储
- Chart.js 图表
- Gemini API（AI 识别）
- RSS 新闻聚合
